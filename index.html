Projects:

Media Assistant

Media Assistant is an open-source Roku app that allows you to stream/play local and hosted media on your Roku device through cast-style API requests. It was built to easily work in tandem with other applications, allowing for a simple API to display media on Roku devices. I created the app to solve the problem of open-source applications, like Home Assistant and Music Assistant, not being able to send media to Roku devices. Both Home Assistant and Music Assistant now natively support media playback on Roku through the Media Assistant Roku app. Check it out at the link to my GitHub below.

Learn more on the Media Assistant's Website

Sparkle Visualizer

Sparkle is a configurable and customizable audio visualizer for Unity. It can display audio in the form of spectrograms and waveforms from a file or microphone. I created this to be easily implemented into other Unity projects that require an audio visualizer. An interactive demo of Sparkle can be found on my Itch.io page.

Learn more on Itch.io

Matrix Display Simulator

This is a configurable simulator of text matrix displays made for Unity. It can display or scroll messages in the style of real life matrix displays like those found in busses and at airports. I created this to be easily implemented into other Unity projects that require a matrix display, for example on a sign or in a vehicle. An interactive demo of the matrix display can be found on my Itch.io page.

Learn more on Itch.io

Rally Waffle JS

Rally Waffle JS is a web-based item-collecting game programmed in JavaScript, where you try to collect all the maple syrups as fast as you can without running out of fuel or getting hit by any of the enemy Pancakes. The goal is to get the fastest time with the least number of deaths.

Play on Rally Waffle JS's Website

MI - 231 Earthbound Beginnings

This game was created for my Classic Game Project in MI 231, where we had to recreate the core mechanics of a classic NES game. The game I picked was Earthbound Beginnings (aka Mother in Japan). I decided to implement the basics of the overworld system, as well as the battle system. In this recreation, you are able to move around the first section of the world, as well as enter Ninten's house. You can also check items like the sign in front of Ninten's house and battle random encounters from a pool of enemies. This project has been cleaned up and bug fixed since I took the class, and can be played at the Itch.io link below.

About Me:

Joseph Friend

Hi, my name is Joseph Friend! I'm a passionate Games and Interactive Media major at Michigan State University. I've loved video games for as long as I can remember. My dad first introduced me to classics like Pacman, Dig Dug, and Burger Time as a kid. I was obsessed! I would spend hours fiddling with my dad's arcade machine in the basement. I have fond memories of playing games like Pokémon Leaf Green on my hand-me-down GBA. I've always been interested in how things work, especially technology. At a young age I started disassembling and rebuilding pens, to my mom's dismay. Progressing all the way to building and repairing computers and electronics. This led me to a position at MSU's IT department at 16. That same drive to understand and create pushed me in high school to learn programming through FIRST Robotics, web development, and game engines like Unity and Unreal Engine. Now at MSU, I'm honing my skills through the Games and Interactive Media program. My goal is to create games and experiences that bring the same joy and excitement to others that gaming has always brought to me.
